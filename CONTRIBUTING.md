# Contributing to Laukolaroser

1. Open an [issue](https://github.com/lowmentaldamage/school_app_openfront/issues) describing the bug or feature.
2. Create a branch, make the change, and add tests (`tests/`). Engine changes (`packages/engine*`) must include tests.
3. Run `npm run typecheck`, `npm run lint`, `npm run format` and `npm test`.
4. Open a pull request using the template.

User-visible text goes through `translateText()` with the English string in
`resources/lang/en.json`.
