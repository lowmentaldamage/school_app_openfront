LAUKOLAROSER — Windows test build
=================================

1. Unzip this folder anywhere (e.g. Desktop). Keep all files together.
2. Double-click "Start Laukolaroser.bat".
   - Windows may show "Windows protected your PC": click "More info" ->
     "Run anyway" (the build is not code-signed).
   - Allow Node.js through the firewall if asked (needed for phones).
3. First start: type an admin username and password in the black window.
4. The game opens in your browser at http://localhost:3000.
   Phones/PCs on the same Wi-Fi use the address shown in the window
   (http://192.168.x.x:3000) — in a browser or in the Android app.
5. Players tap "Request access"; you approve them in the menu
   (your name, bottom-left -> Manage players).

Keep the black window open while playing; close it to stop the server.
Accounts, stats and settings are kept in the "data" folder.

Full guides: docs/PlayerGuide.md, docs/SelfHosting.md, docs/Install.md
